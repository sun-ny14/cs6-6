# 코드 통합 내역

## 2026-09-02 Go Live 실행 설정

- `.vscode/settings.json`에서 특정 PC의 절대 경로에 의존하던 사용자 지정 실행 명령을 해제했습니다.
- Go Live가 프로젝트 루트를 제공하고 Chrome에서 화면을 열도록 설정했습니다. 기존 두 프로필 실행 스크립트는 파일로 보관하되 Go Live에서 자동 호출하지 않습니다.
- 설정을 적용한 뒤 Live Server를 중지하고 다시 시작합니다. 자동 브라우저 실행이 계속 실패하면 Chrome에서 `http://127.0.0.1:5500/index.html` 또는 `http://127.0.0.1:5500/blackboard.html`을 직접 엽니다.
- JSON 형식과 실행 설정값을 검증했습니다. 실제 사용자 Windows에서의 브라우저 실행은 별도 확인이 필요합니다.

## 2026-09-02 기기 간 전자칠판 공유

- 로그인하지 않은 전자칠판은 `blackboardDisplay`만 실시간으로 읽습니다. 원본 사용자·포인트·출결 기록에는 접근하지 않습니다.
- 새 버전 로그인 앱은 `js/blackboard-share.js`로 화면 표시 필드만 골라 공유 경로를 갱신합니다.
- 기본 시간표를 실제 저장된 내용처럼 표시하던 오류를 막고, 초기 공유 대기·읽기 거부 안내를 추가했습니다.
- `database.rules.json`을 Firebase 규칙에 게시해야 합니다. 자세한 적용 순서와 공개 범위·동기화 제한은 `BLACKBOARD_SETUP.md`에 있습니다.

## 2026-09-02 전자칠판 자동 전환

- 메모 입력칸에 포커스가 있으면 화면 갱신을 무조건 중단하던 동작을 수정했습니다. 같은 교시에서는 입력 상태를 유지하고, 교시·쉬는 시간·날짜가 바뀌면 메모 저장을 요청한 뒤 해당 시간 화면으로 전환합니다.
- 시간표를 클릭한 수동 미리보기는 다음 시간 구간에서 자동 모드로 복귀합니다. 즉시 복귀 버튼도 유지합니다.
- 날짜와 주가 바뀌어도 작성하던 메모는 원래 날짜와 교시에 저장합니다.
- 창으로 돌아오거나 절전에서 복귀하면 현재 시간에 맞게 화면을 갱신합니다.
- `node --test tests/blackboard.test.cjs`의 11개 시나리오로 교시 전환, 메모 포커스, 수동 복귀, 날짜 경계, 사용자 지정 시간표를 검증했습니다. 실제 교실 계정과 기기의 브라우저 검증은 포함하지 않습니다.

## 2026-09-02 친구 방·이모지 방명록

- 친구 카드 클릭을 실제 방 렌더러에 연결하고 `이름의 방`을 표시합니다.
- 방 탭을 직접 열면 내 방으로 돌아옵니다. 내 방에서만 상점, 보관함, 배경 선택 및 가구 편집이 가능합니다.
- 친구 방에는 이모지 반응과 방명록 확인만 표시합니다. 내 방에서도 받은 반응을 확인할 수 있습니다.
- 친구별·방문자별 하루 한 번만 반응을 남깁니다. 한국 시간 날짜를 사용하고 서버 시간 차이를 보정합니다.
- 일일 반응 기록과 방명록을 같은 Realtime Database 트랜잭션에 저장합니다. 기존 방·가구·방명록 데이터는 보존합니다.
- 학생과 관리자 모두 상점 내부의 닫기 버튼을 이용할 수 있습니다.
- `node --test tests/housing.test.cjs`로 방 전환, 권한 분리, 동시 반응, 날짜 경계, 저장 실패와 기존 기록 호환성을 검증합니다. 테스트는 모의 데이터베이스를 사용하며 실제 Firebase 권한과 브라우저 화면 확인은 포함하지 않습니다.
